# C1 Risicoanalyse voor gebreken




##  Inleiding
In dit hoofdstuk staat beschreven hoe de risico's worden ingeschat bij de uitkomsten van de conditiescores. Dit betreft een risico-analyse voor de gebreken, er zijn meer risico-analyses denkbaar maar die worden hier niet uitgewerkt. 
De NEN inspectie kan je niet zonder een risico beoordeling uitvoeren. Dit omdat een rijdek met 1 gat een geaggregeerde score goed krijgt maar op risico een hoog profiel. Daarmee is direct herstel noodzakelijk.  


## Beleid
Afhankeliujk van het lokale beleid kan de risicomatrix er anders uit zien. Toch is een voorbeeld opgenomen waarmee i nde basis gewerkt kan worden door elke gemeente.
